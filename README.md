# Go Cloud Native Learning

Bu proje; Go, Docker, Docker Compose, Kubernetes, Metrics Server, HPA ve k6 teknolojilerini iki basit HTTP servisi üzerinden öğrenmek amacıyla geliştirilmektedir.

## Projenin amacı

- Go ile iki bağımsız HTTP servisi geliştirmek
- Servisleri düzenli ve test edilebilir bir klasör yapısıyla oluşturmak
- Servisleri Docker image haline getirmek
- Docker Compose ile birlikte çalıştırmak
- k6 ile yük ve stres testi yapmak
- Kubernetes üzerinde deploy etmek
- Metrics Server ile kaynak kullanımını gözlemlemek
- HPA ile Pod sayısının otomatik değişmesini incelemek
