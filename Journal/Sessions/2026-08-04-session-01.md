## Ne öğrendim?

- `Get-Location` komutunun bulunduğum klasörü gösterdiğini öğrendim.
- `Get-ChildItem` komutunun bulunduğum klasörün altındaki öğeleri listelediğini öğrendim.
- `Get-ChildItem -Force` komutunun `.git` gibi gizli öğeleri de gösterdiğini öğrendim.
- `Get-ChildItem -Recurse` komutunun alt klasörlerin içine de girerek listeleme yaptığını öğrendim.
- `.git` klasörünün Git repository bilgilerini tuttuğunu öğrendim.
- `.gitignore` dosyasının Git tarafından takip edilmemesi gereken dosyaları belirlediğini öğrendim.
- Git'in boş klasörleri doğrudan takip etmediğini öğrendim.
- Yerel Git repository ile GitHub repository'nin aynı şey olmadığını öğrendim.
- Dosya ve klasörlerin önce yerel bilgisayarda oluşturulduğunu öğrendim.
- Working directory, staging area ve repository arasındaki farkı öğrendim.
- `git add` komutunun dosyaları commit etmediğini, staging area'ya aldığını öğrendim.
- `git commit` komutunun staged değişiklikleri yerel Git geçmişine kaydettiğini öğrendim.
- `git push` komutunun yerel commit'leri GitHub'a gönderdiğini öğrendim.
- Commit hash değerinin commit'i tanımlayan benzersiz bir kimlik olduğunu öğrendim.
- `HEAD` işaretçisinin şu anda üzerinde bulunduğum commit'i gösterdiğini öğrendim.
- `origin` adının uzak repository için kullanılan standart kısa ad olduğunu öğrendim.
- `origin/main` ifadesinin GitHub üzerindeki `main` branch'ini gösterdiğini öğrendim.
- `-u` parametresinin yerel ve uzak branch arasında takip ilişkisi kurduğunu öğrendim.
- `git diff` komutunun working directory ile staging area arasındaki farkı gösterdiğini öğrendim.
- `git diff --staged` komutunun staging area ile son commit arasındaki farkı gösterdiğini öğrendim.
- `git restore --staged` komutunun dosyayı silmeden staging area'dan çıkardığını öğrendim.
- `working tree clean` ifadesinin commit edilmemiş değişiklik bulunmadığını gösterdiğini öğrendim.
